# Loopsmith plugin

Your Loopsmith studio (running on RunPod) inside your DAW, as an AU and VST3 plugin for macOS.

- Open the studio in a plugin window and log in.
- Click the arrow button on any sound, then drag it from the bar at the bottom onto a track.
- "Capture this track" records what plays through the plugin and sends it to the studio.

GitHub builds the Mac plugin automatically whenever this code changes: look under
**Releases** on the right of this page for `Loopsmith-Plugin-Mac.zip`.
Intel and Apple Silicon, macOS 10.15 or newer.
